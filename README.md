# Caleb

SaaS de administración para emprendedores en Colombia: recibos de venta, cuentas por cobrar y por
pagar, inventario, servicios y flujo de caja semanal.

## Estructura

- `front/` — React + TypeScript + Vite
- `back/` — FastAPI
- `deploy/` — Dockerfiles, docker-compose y Nginx

La documentación del negocio vive en Obsidian, fuera de este repo.

## Ramas

`development` (desarrollo local) → `qa` (ensayo) → `main` (producción). Siempre en ese orden.
